# 🌱 Cloud-Based Crop Monitoring System

![Crop Monitoring System](assets/crop_monitoring.png)

A fully automated cloud-based crop monitoring system designed to provide real-time information about important environmental conditions affecting crops. The system uses an ESP32 to collect sensor data and makes the information accessible remotely through an internet connection.

## 🚀 Project Overview

The system continuously monitors:

- 🌱 **Soil Moisture** – Helps monitor the moisture level of the soil.
- 💧 **Humidity** – Measures surrounding humidity using the DHT22.
- 🌡️ **Temperature** – Provides real-time temperature readings.
- 🌧️ **Rainfall Detection** – Detects rainfall conditions.
- 📊 **Atmospheric Pressure** – Measures pressure using the BMP280 sensor.

## 🔧 Components Used

- ESP32
- Soil Moisture Sensor
- Rainfall Detection Sensor
- DHT22 Temperature & Humidity Sensor
- BMP280 Pressure Sensor
- Zero PCB
- Male/Female Jumper Wires
- Male/Female Header Pins

## ☁️ Cloud Connectivity

The ESP32 acts as the main controller, collecting data from the connected sensors and transmitting the readings through an internet connection. This allows the crop-monitoring data to be accessed remotely, supporting convenient and efficient monitoring.

## 🎯 Objective

The main objective of this project is to use IoT and cloud-based technology for smarter crop monitoring, providing real-time environmental data that can help in efficient crop management.

## 🔮 Future Scope

The system can be further improved by adding automated irrigation, cloud-based data visualization, alerts, historical data analysis, and additional agricultural sensors.
